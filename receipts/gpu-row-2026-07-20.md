## Battery (semantics)

`python -m pytest gpu/tests/ -q` on-box: **16/16 green, 100
hypothesis examples per property.** s64 lanes bit-exact against the
definitional pure-Python reference at full i64 range (wraparound
included) over generated rows (diagonals, broadcast axes, scalar
factors, empty tensor product); FFI fresh + aliased accumulate;
Pallas hadamard-accumulate both twins (jnp ops vs literal
`mad.lo.s64`); interval family bitwise against the exact-rational
oracle with the enclosure property checked in exact arithmetic;
fused-Pallas directed adds bitwise against the FFI kernel.

Finding worth its own line: the battery's first run **falsified the
oracle, not the kernels** — the naive Fraction reference missed IEEE
754's signed-zero rules (an exactly-cancelling `add.rm` yields -0.0;
exact-zero products carry the XOR of operand signs). The device was
right; the oracle now spells the exact-zero cases out
(`gpu/interval.py`). Exact rationals carry no signed zero — a
DATERWI oracle must add IEEE's sign semantics explicitly.

## Honest readings (what licenses what)

- **Dispatch for large contractions stays with the XLA emission
  lane.** The generic descriptor kernel loses 13x to XLA's tiled s64
  dot at 512^3 (2.28 vs 0.168 ms) — per-element div/mod decode and
  zero data reuse, exactly as expected of a first rows-as-data
  kernel. What the FFI embedding buys is not big-matmul speed: rows
  as runtime data (no recompile per row), the aliased in-place
  accumulate, and the per-instruction rounding control no emitted op
  offers. A tiled/shape-specialized variant is the obvious successor
  if a consumer ever needs big contractions off-XLA.
- **At small shapes the custom call is competitive with XLA's own
  emission** (32K hadamard: 0.066 vs 0.068 ms) — the boundary is
  launch-dominated, consistent with the upstream finding that an
  aliased custom call is free at the boundary.
- **The inline-PTX island costs nothing at its scope**: pallas accum
  jnp twin 0.105 ms vs literal-PTX `mad.lo.s64` 0.101 ms, verdicts
  bit-identical. The soundness-relevant consequence: directed-rounding
  arithmetic can join a fused kernel at no premium
  (interval add 32K fused: 0.138 ms).
- **Caveat on the `accum, aliased` rows**: the timed closure
  regenerates a fresh random accumulator every rep (donation consumes
  it), so those rows measure regeneration + accumulate, not the
  accumulate alone — read them against each other, not against the
  fresh rows. A donation-free steady-state loop is the honest
  instrument for the resident-update path; building it into the bench
  is queued for the next receipt.
- **Compile-cliff warning, s64 einsum, jax 0.11.0**: the 1024^3 s64
  einsum's autotuning compile ran past 20 minutes and died to the
  32 GB memory ceiling (host-side, during compile — the leg's OOM,
  not the kernel's). The persistent compilation cache
  (`jax_compilation_cache_dir`) is the mitigation for shapes that do
  compile: measured cold 4.58 s -> warm 0.025 s on an unrelated
  32-matmul program on this box. Budget s64 big-dot compiles
  deliberately.
- **Pallas lane scope ceiling is real**: one asm op per register at
  trace time means a 4M-element single-block call explodes MLIR
  (slow-compile alarm, never returned); the lane refuses above
  `MAX_ELEMENTS` = 32768. Grid tiling is the growth path when a
  consumer wants it.
